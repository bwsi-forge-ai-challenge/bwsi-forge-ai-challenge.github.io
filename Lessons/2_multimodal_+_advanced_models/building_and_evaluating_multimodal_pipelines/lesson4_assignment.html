Assignment: Evaluate a Multimodal Model

Test a small open vision-language model to find out whether it actually looks at the image or just guesses from the question.

Starter notebook: multimodal_evaluation_assignment.ipynb
Environment: Google Colab with a free T4 GPU. The notebook loads the model for you.
Suggested time: about 1 hour
Companion reading: Evaluation, Benchmarks, and Safety

Download the starter notebook below, complete the TODOs inside it, and run all cells before submitting.

The test set is 30 pairs of real photos (about 5 MB). The notebook downloads them for you. If that download fails, download the zip below, upload it in Colab's Files panel, and run the download cell again.

Download multimodal_evaluation_assignment.ipynb
Download multimodal_eval_images.zip (only if the notebook's download fails)

What You Will Do

PartTaskWhat it shows
1Write extract_answer to score free-form answers fairlyWhy exact string matching is unfair to chatty models
2Write run_condition to ask every question under one condition, then run the model on 30 pairs of real photosAccuracy per category and latency per question
3Write the reliance gap, change rate, and flip rate, then build evaluate_model from run_conditionWhether the model uses the image or guesses from the question

Parts 2 and 3 each end with a short written reflection, stored as a Python string in the notebook.

Submitting Your Work

  1. Complete every TODO and both reflections (part2_reflection and part3_reflection). Keep every function name and signature exactly as given: the autograder tests your evaluation functions on its own models, through the ask_fn argument.
  2. Run every cell in the notebook from top to bottom without errors.
  3. Export the notebook as a Python script (File → Download → Download .py in Colab) and rename it to firstname_lastname_model_eval.py.
  4. Submit only that .py file on Gradescope: Evaluate a Multimodal Model assignment.

If you can't access the Gradescope link, go to the Gradescope for this class (if you are logged in you should be able to see this course when you visit the Gradescope home page), select this course, and then pick the Evaluate a Multimodal Model assignment.
