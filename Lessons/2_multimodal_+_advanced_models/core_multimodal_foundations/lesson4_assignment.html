Assignment: Similarity Matrices and Projection Heads

Build the core machinery behind CLIP-style models from scratch: cosine similarity, image-by-text similarity matrices, and a pair of projection heads trained with the contrastive loss.

Starter notebook: similarity_matrices_assignment.ipynb
Environment: Google Colab or local Python with NumPy, PyTorch, and Matplotlib. A CPU is enough; no GPU or model downloads are needed.
Suggested time: 1.5 to 2 hours
Companion reading: Multimodal Representation and Latent Spaces

Download the starter notebook below, complete the TODOs inside it, and run all cells before submitting. Each part ends with a check cell that tells you whether your code is correct.

Download similarity_matrices_assignment.ipynb

What You Will Do

PartTaskWhat it shows
1Write cosine similaritySimilarity depends on direction, not length
2Build a 4 × 4 image-by-caption similarity matrix with one matrix multiplication, then retrieve in both directionsHow a shared space turns matching into a lookup
3Try to compare features from two simulated encoders with different sizes, then add random projection headsMatching the shapes is not the same as matching the meaning
4Implement the symmetric InfoNCE loss and train two projection headsContrastive training makes a diagonal appear on pairs the model never saw
5Sweep the temperature and plot test accuracyWhy the temperature has a sweet spot

Parts 2, 4, and 5 each end with a short written reflection, stored as a Python string in the notebook.
