Assignment: Evaluate a Multimodal Model

Find an open vision-language model on Hugging Face, build an evaluation harness that tests whether it actually looks at the image, and report what you found in an evaluation card.

Starter notebook: multimodal_evaluation_assignment.ipynb
Environment: Google Colab with a free T4 GPU, using an open model from Hugging Face that you choose.
Suggested time: 2 to 2.5 hours
Companion reading: Evaluation, Benchmarks, and Safety

Download the starter notebook below, complete the TODOs inside it, and run all cells before submitting. Each part ends with a check cell that tells you whether your code is correct. The notebook includes two practice models with known behavior, so you can test your evaluation code before running your real model.

The test set is 30 pairs of real photos (about 5 MB). The notebook downloads them for you. If that download fails, download the zip below, upload it in Colab's Files panel, and run the download cell again. You will also take a few photos of your own for Part 5, so have a phone camera handy.

Download multimodal_evaluation_assignment.ipynb
Download multimodal_eval_images.zip (only if the notebook's download fails)

What You Will Do

PartTaskWhat it shows
1Choose an image-and-text model on Hugging Face that fits a free T4, record what its model card claims, and wrap it in an ask(image, question) functionHow to read a model card and run a model you did not build
2Write normalize and extract_answer to score free-form answers against a provided set of 30 pairs of real photosWhy exact string matching is unfair to chatty models
3Write run_condition to ask every question under one condition and time each model callAccuracy per category and latency per question
4Implement the reliance gap, change rate, and flip rate, then combine everything into evaluate_modelWhether the model uses the image or guesses from the question
5Design a test category of your own with pairs of photos you take, and evaluate your model on itHow to write a test whose answers depend on the input
6Fill in an evaluation card: summary, grounding verdict, claimed versus measured results, limitations, and a deployment recommendationHow to report an evaluation honestly

Parts 3 and 4 each end with a short written reflection, stored as a Python string in the notebook.

Submitting Your Work

  1. Complete every TODO, both reflections (part3_reflection and part4_reflection), and every field of the evaluation card. Keep every function name and signature exactly as given: the autograder tests your evaluation functions on its own models, through the ask_fn argument.
  2. Run every cell in the notebook from top to bottom and confirm that every check cell passes.
  3. Export the notebook as a Python script (File → Download → Download .py in Colab) and rename it to firstname_lastname_model_eval.py.
  4. Submit only that .py file on Gradescope: Evaluate a Multimodal Model assignment.

If you can't access the Gradescope link, go to the Gradescope for this class (if you are logged in you should be able to see this course when you visit the Gradescope home page), select this course, and then pick the Evaluate a Multimodal Model assignment.
