Assignment: Download, Run, and Fine-Tune a Real Model

This assignment applies everything from this unit in one hands-on workflow. You will load a small open-source model, see how a base model behaves, fine-tune it on a narrow task, log runs to Weights & Biases, and compare results.

What are you actually doing?

You are not pretraining a model from scratch (that takes months and millions of dollars). You are:

  1. Downloading a model someone else already trained (DistilGPT-2 from Hugging Face).
  2. Running it to see that raw models often continue text instead of following instructions.
  3. Fine-tuning — showing it 50+ examples of a specific task so its weights shift toward that behavior.
  4. Logging training to W&B so you can compare two experiments (different learning rates) like real ML teams.

The notebook walks you through every step with explanations. Read the Key terms section in the notebook before you run code.

What is Weights & Biases?

Fine-tuning involves trial and error: change learning rate, train again, change epochs, train again. Without a log, you forget what you tried.

W&B is a free tool that automatically records:

  • A loss curve (line chart showing training error over time)
  • The hyperparameters you used (learning rate, batch size, epochs)
  • Multiple runs you can overlay to see which settings worked best

PART 2
Prepare a Small Fine-Tuning Dataset

Goal: Build teaching material for the model. Each row is an input (what a user types) and an output (the answer you want). Fine-tuning learns from these pairs — the model never sees your task rules written in English, only your examples.

Choose a narrow, well-defined task. Examples:

  • Completing sentences in a specific style (pirate speak, Shakespearean English)
  • Answering simple domain-specific questions (trivia about one topic)
  • Formatting text a certain way (casual → formal business English)

Build 50–200 input/output pairs. Sources:

  • Hand-written examples (best for quality)
  • Small public dataset adapted to input/output pairs
  • Another AI tool to draft examples — then you review and edit for consistency

The notebook includes ~25 starter pairs for a casual → formal business English task. You must add at least 25 more (TODO in Part 2) or replace the task entirely with your own 50+ pairs.

Written reflection (one page)

Troubleshooting

IssueTry this
CUDA out of memoryReduce batch_size to 2, shorten max_length, use distilgpt2
W&B login errorRun wandb.login() with API key; or set WANDB_MODE=disabled to finish locally (still submit runs for credit if possible)
Loss not decreasingTry higher LR slightly; check dataset formatting; verify labels are not all padding
Model ignores task after fine-tuneMore epochs or examples; ensure prompt format at inference matches training format
