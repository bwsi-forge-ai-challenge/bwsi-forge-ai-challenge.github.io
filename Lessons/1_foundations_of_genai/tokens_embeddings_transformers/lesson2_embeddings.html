Embeddings: Meaning in Vector Space

The Mathematical Dilemma: In the previous lesson, we transformed raw text tokens into standard index integers. However, numerical tokens are inherently empty values. To a model, Token ID 5000 and Token ID 5001 are isolated indices lacking any internal notion of relational context or similarity. To achieve true understanding, we must shift away from sequential numbers toward Embeddings: continuous, multi-dimensional floating-point vectors that map semantic relationships cleanly across a shared spatial geometry. Note that everything we are talking about in this section is in regards to text-to-text generation.

1. The Limitation of Arbitrary Integer Spaces

When compiling a basic token text dictionary, vocabulary words receive numerical indicators based entirely on structural sequencing or dataset appearance sorting. This creates major semantic issues:

  • The concept structures "king" and "queen" represent highly related contexts, yet their assigned token values could end up as drastically separate listings like 5000 and 8721.
  • Conversely, completely unrelated random phrases might be given adjacent index rows simply due to chronological ordering.
  • An index integer contains zero intrinsic information regarding grammatical properties, emotional tone, or conceptual definitions.

To overcome this, we establish a specialized dense translation table that converts static integers into arrays of coordinates within a high-dimensional vector space.

2. Building Dense Feature Representations

An embedding matrix is a large, trainable lookup system. When given a token ID, it serves as a pointer to extract a precise vector of real numbers. While historical baseline configurations like GPT-2 utilized 768 dimensions per token, enterprise frontier LLMs scale up to 4,096 to 8,192+ dimensions.

Token ID 5000 ➔ Embedding Layer Weight Matrix Lookup ➔ [0.82, 0.61, -0.15, ...]
Token Input Target Assigned Token ID Extracted Weight Vector Map (Truncated Samples)
king 5000 [ 0.82, 0.61, 0.15, 0.44, -0.08 ]
queen 8721 [ 0.74, 0.59, -0.12, 0.41, -0.06 ]
apple 1203 [-0.55, -0.48, 0.05, -0.33, 0.22 ]

Crucially, these dimensional metrics are never programmed by hand. They are optimized dynamically via gradient descent updates during training. Individual coordinates do not align with isolated, human-labeled concepts like "gender" or "temperature." Instead, the complete combination of dimensions wraps deep mathematical relationships from text patterns into a dense geometric profile.

3. The Geometry of Meaning

In this high-dimensional space, proximity mirrors semantics. Tokens that frequently share adjacent sentence structures in training data are progressively updated until their target vectors cluster close together.

Concept Coordinate Illustrative Spatial Position Coordinates Localized Neighbor Clusters
king (0.8, 0.6) queen, prince, monarch, throne
man (0.3, 0.1) woman, person, human, individual
apple (-0.5, -0.5) fruit, carrot, food, orchard

4. Mathematical Analogies

Because these positions are standard numerical coordinates, we can perform vector arithmetic on word meanings. The classic example is:

\[\vec{v}_{\text{king}} - \vec{v}_{\text{man}} + \vec{v}_{\text{woman}} \approx \vec{v}_{\text{queen}}\]

By subtracting the vector for "man" from "king", the model mathematically strips away the masculine trait while retaining the core royal attribute. Adding the vector for "woman" then moves the coordinates to the closest spatial point matching a feminine royal identity: "queen".

Additional Emergent Linear Trajectories:
  • Paris - France + Germany ≈ Berlin (Capital relationships)
  • programmer - Python + Java ≈ developer (Domain translations)

5. Contextualized Evolution: Navigating Homonyms

A major limitation of basic dictionary embeddings is their static nature: an isolated word token receives exactly one vector entry. This breaks when managing words with multiple meanings:

How can we map the word "bank" in both "river bank" and "investment bank"?

The Transformer Core Fix: While a word always pulls the same base lookup vector initial coordinates, subsequent internal Self-Attention Layers mathematically modify the initial state based on surrounding text context. This dynamically shifts the base coordinates toward the appropriate financial or nature neighborhoods before evaluating meaning.

Context String Dynamic Real-Time Vector Drift Response
"I went to the bank to withdraw money." Vector coordinates drift toward the financial cluster.
"I sat on the bank of the winding river." Vector coordinates drift toward the nature and geography cluster.
