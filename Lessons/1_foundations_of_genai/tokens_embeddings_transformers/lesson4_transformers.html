Transformers: Putting It All Together

Lessons 1–3 covered tokenization, embeddings, and attention in isolation. A transformer stacks these pieces into a trainable system that reads a token sequence and predicts what comes next. This lesson walks through the full pipeline — from text to logits — and shows how autoregressive models like GPT generate one token at a time.

1. Architecture Overview

A transformer processes text through repeated layers. Each layer applies self-attention (tokens exchange information) plus a feed-forward network (per-token refinement). GPT-3 stacks 96 such layers; GPT-2 small uses 12.

Training objective: predict the next token. At inference, sample or argmax one token, append it, repeat.

Text → Token IDs → Embed + Position → Layer × N → Logits (50K) → Softmax → Next token

Shape trail: (seq_len,) → (seq_len, d) → (seq_len, d) → (seq_len, vocab)

2. The Full Pipeline: "The cat sat"

  1. Tokenize: ["The", " cat", " sat"] → IDs [50, 3277, 2521]
  2. Embed: each ID → 768-d vector (lookup table)
  3. Position encode: add sinusoidal or learned position vector per slot
  4. Layers 1…N: multi-head attention + feed-forward + residual + layer norm (each layer)
  5. Final token hidden state: vector at last position ("sat")
  6. Project to vocabulary: linear layer → 50,257 logits
  7. Softmax: probabilities over all next tokens
  8. Sample / argmax: e.g. " on" → sequence becomes "The cat sat on"

Depth intuition: early layers often capture local syntax; deeper layers integrate semantics and task-specific patterns. Representations refine layer by layer — not a strict partition, but a useful mental model.

4. Autoregressive Generation

GPT-style models are decoder-only and causal: when predicting token t, attention is masked so position t cannot see future tokens. Generation loop:

StepInput sequencePredicted next
1The cat saton
2The cat sat onthe
3The cat sat on themat

Stop at max length or a special end-of-text token.

5. Transformers vs RNNs

PropertyRNN / LSTMTransformer
ProcessingSequential, one step at a timeParallel over sequence (training)
Long-range linksThrough many hops; gradient decayDirect attention in one layer
ScaleHarder to scale to huge dataScaling laws favor bigger models + data
AttentionHand-designed gatesLearned softmax attention

6. Limitations and Quirks

  • Context window: fixed max length (e.g. 4K–128K tokens). Beyond that → truncate, summarize, or chunk.
  • Next-token objective: no explicit reasoning engine — behavior emerges from prediction.
  • Hallucination: plausible-sounding tokens when data is missing.
  • O(n²) attention: long sequences are compute-heavy.
  • Causal masking (GPT): cannot look ahead during training; encoder-decoder models (T5) use bidirectional encoding on input.
