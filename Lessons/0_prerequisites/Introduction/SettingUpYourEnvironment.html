Setting Up Your Environment

Coding assignments in this course run as Jupyter notebooks. If you have your own GPU, feel free to use that on your machine. If not, you can execute them in Google Colab, which provides a free browser-based Python environment and an optional free GPU. This page covers the setup for Google Colab and can be skipped if using local GPU.

1. What you will use

Assignment notebooks are .ipynb files. Colab runs the cells in the cloud and can attach a free GPU when training would otherwise be slow on CPU.

ToolRole
Google Colab Host the notebook, run cells, attach a free GPU
Python packages Provided in Colab or installed from a cell in the notebook when needed
Free GPU Speeds up model training; notebooks check for it automatically when available

Interactive HTML lessons run in the browser and do not require Colab. Use Colab for the coding assignment notebooks.

2. Create a Google account

Colab requires a Google account. If you do not already have one, create an account at accounts.google.com. Use a personal Google account that you can access for the full course.

3. Open an assignment in Colab

When an assignment notebook is released, open it in Colab using one of these methods:

Upload the file

  1. Go to colab.research.google.com.
  2. Choose File → Upload notebook.
  3. Select the .ipynb file from your computer.

Open from Google Drive

  1. Upload the notebook to Drive.
  2. Right-click the file → Open with → Google Colaboratory.

Open from GitHub (if the course posts a link)

  1. In Colab, choose File → Open notebook → GitHub.
  2. Paste the repository URL or notebook path provided by the instructors.

After opening, run cells from top to bottom with Shift+Enter, or use Runtime → Run all once you have completed any TODO cells.

4. Enable the free GPU

Training runs much faster on a GPU. Enable it before the training sections of each assignment:

  1. In the Colab menu, open Runtime → Change runtime type.
  2. Set Hardware accelerator to T4 GPU (or any available GPU).
  3. Click Save.
  4. Re-run the setup cell so the notebook picks up the new device.

Most assignment notebooks print which device they are using after the setup cell. Confirm that output shows a GPU (often labeled cuda). If it shows cpu, the GPU is not attached — return to Change runtime type and confirm the accelerator setting.

5. Libraries and installs

Colab already includes many common scientific and deep learning packages. Each assignment notebook lists what it needs. If an import fails, look for a commented install cell near the top, for example:

# !pip install -q package_name

Uncomment and run that cell only if the imports fail, then re-run the import cell.

6. Recommended workflow

  1. Read the companion lesson named in the notebook before you start coding.
  2. Enable the GPU before long training cells.
  3. Complete TODOs in order and run any provided checks after each part.
  4. Save a copy with File → Save a copy in Drive so your work survives session disconnects.
  5. Download your finished notebook (File → Download → Download .ipynb) when you are ready to submit.

Sessions disconnect

Colab sessions disconnect after idle time. Reconnecting starts a new runtime: re-enable the GPU if needed, then re-run cells from the top through your current progress.

7. Common problems

SymptomFix
Notebook reports CPU during training Runtime → Change runtime type → T4 GPU, then re-run the setup cell
GPU option missing or unavailable Wait and retry later, or continue on CPU for short experiments (training will be slower)
ModuleNotFoundError Run the notebook's pip install cell, then re-run the import cell
Session disconnected; variables gone Re-run from the top; restore from your Drive copy if you edited cells
Checks fail after a TODO Fix that section before moving on; later parts depend on earlier results
