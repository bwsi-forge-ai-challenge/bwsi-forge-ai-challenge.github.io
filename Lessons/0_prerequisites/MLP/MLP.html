Multi-Layer Perceptrons and Backpropagation

Lesson 4 demonstrated that mapping non-linear spaces like the XOR distribution requires isolating intermediate feature coordinates. A multi-layer perceptron (MLP) generalizes this architecture by stacking multiple computational layers separated by non-linear activation functions, utilizing the backpropagation algorithm to optimize all parameter weights concurrently.

1. MLP topology

An MLP is organized into three distinct structural zones:

  • Input layer — Comprises one node per feature dimension (e.g., 256 nodes to ingest a flattened \(16 \times 16\) grayscale pixel array).
  • Hidden layers — Intermediate layers that transform raw inputs into high-dimensional latent representations.
  • Output layer — Contains one target node per classification category (e.g., 10 nodes for digit classes 0–9).

For a network structured with layer dimensions \(n_0 \to n_1 \to n_2 \to n_3\), the total quantity of trainable parameters is calculated via:

\[\text{Number of Parameters} = \sum_{l} (n_l \cdot n_{l+1} + n_{l+1})\]

The \(n_{l+1}\) term accounts for the independent bias scalar allocated to each destination neuron. Under this formula, a \(256 \to 32 \to 16 \to 10\) topology contains \((256 \times 32 + 32) + (32 \times 16 + 16) + (16 \times 10 + 10) = 8,426\) parameters. Increasing layer width and depth enhances the model's capacity to represent high-variance functions, though it increases empirical variance and the risk of overfitting on finite training sets.

2. The forward propagation pass

Data propagates sequentially through the network graph. Each layer computes an affine transformation followed by an element-wise non-linear activation:

\[z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}\] \[a^{(l)} = \sigma(z^{(l)})\]

  • \(a^{(0)} = x\) — The initial input vector of dimensions \([n_0]\).
  • \(W^{(l)}\) — The transformation weight matrix of dimensions \([n_l, n_{l-1}]\).
  • \(z^{(l)}\) — The pre-activation vector compiled prior to non-linear mapping.
  • \(\sigma\) — The localized activation function (such as ReLU, sigmoid, or tanh).

The final output layer typically applies an activation function to normalize raw logit scores into a valid multinomial probability distribution that integrates to 1. The forward pass is purely deterministic matrix arithmetic; parameter optimization does not occur until an error metric is evaluated and gradients flow in reverse.

A fully connected layer (also called a dense layer) is the basic computation unit in an MLP. It means every neuron in the layer receives input from every neuron in the previous layer. The term “dense” refers to this all-to-all connection pattern, where no input feature is ignored and all features contribute to every output neuron through learned weights.

3. Backpropagation mechanics

A single full iteration combines one forward evaluation pass with one reverse propagation pass to derive the comprehensive gradient matrix for the entire network. Computing these updates across random mini-batches iteratively minimizes the objective function over time.

Backpropagation evaluates the partial derivatives of the loss function \(\frac{\partial L}{\partial w}\) for every weight parameter by systematically chaining derivatives from the output layer back to the input vector. Once the forward pass quantifies the error value \(L\), the gradient at the terminal nodes is established, and each antecedent layer receives an error signal proportional to its contribution to the final variance.

\[\frac{\partial L}{\partial w_{ij}^{(l)}} = \left(\frac{\partial L}{\partial z^{(l)}}\right) \cdot \left(\frac{\partial z^{(l)}}{\partial w_{ij}^{(l)}}\right)\]

The calculus chain rule isolates dependencies across the computation graph. For a specific parameter scaling the connection from node \(j\) in layer \(l-1\) to node \(i\) in layer \(l\), the local gradient component \(\frac{\partial z^{(l)}}{\partial w_{ij}^{(l)}}\) evaluates exactly to \(a_j^{(l-1)}\)—the specific activation magnitude delivered by the preceding node.

Weights are systematically adjusted via standard gradient descent optimization paths:

\[w \leftarrow w - \alpha \frac{\partial L}{\partial w}\]

Remeber \(\alpha\) here is the learning rate for our optimization.

4. Visual walkthrough: one forward pass and one backward pass

The equations above are easier to follow on a network small enough to compute by hand. The walkthrough below uses a 2 → 2 → 1 network with sigmoid activations, one training example \(x = (1.0,\ 0.5)\) with target \(y = 1\), and the squared-error loss \(L = \tfrac{1}{2}(\hat{y} - y)^2\). Step through it and watch the numbers change on the diagram.

The forward pass moves left to right. Each neuron adds up its weighted inputs plus its bias to get \(z\), then applies the activation to get \(a = \sigma(z)\). The output neuron's activation is the prediction \(\hat{y}\), and comparing it with the target gives the loss. Every \(z\) and \(a\) computed along the way is kept, because the backward pass needs them.

The backward pass moves right to left. It answers one question for every weight: if this weight grew slightly, how much would the loss change? To answer it efficiently, backpropagation first computes an error signal for each neuron,

\[\delta^{(l)} = \frac{\partial L}{\partial z^{(l)}},\]

which measures how sensitive the loss is to that neuron's pre-activation. The output neuron's error comes straight from the loss. Each earlier layer's error is the next layer's error sent back along the same weights used in the forward pass, then scaled by the local slope of the activation:

\[\delta^{(l)} = \left( (W^{(l+1)})^{\top} \delta^{(l+1)} \right) \odot \sigma'(z^{(l)})\]

Once a neuron's error is known, the gradient of every weight feeding into it is just (error at the weight's destination) × (activation at the weight's source): \(\frac{\partial L}{\partial w_{ij}^{(l)}} = \delta_i^{(l)} a_j^{(l-1)}\). This is why backpropagation is efficient: one backward sweep reuses the cached forward values and the downstream errors, so every gradient costs about as much as the forward pass itself instead of requiring a separate calculation per weight.

5. The vanishing gradient constraint

Utilizing sigmoid activations introduces distinct mathematical limitations during backpropagation, as the derivative of the sigmoid function caps at \(\sigma'(z) \le 0.25\). Propagating errors backward through an architecture containing \(L\) hidden layers scales the gradient signal down by a maximum factor of \(0.25^L\):

\[\sigma'(z) = \sigma(z)(1 - \sigma(z)) \le 0.25\]

In a 6-layer sigmoid architecture, this dampening effect factors to \(0.25^6 \approx 0.00024\), meaning less than 0.03% of the terminal error gradient reaches the foundational weight parameters. Consequently, these early-stage parameters remain largely unoptimized while only the terminal layers converge. This behavior describes the vanishing gradient problem, which historically restricted the training optimization of deep sigmoid networks.
