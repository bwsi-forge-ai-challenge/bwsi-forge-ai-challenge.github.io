Perceptrons and Hidden Layers

Lesson 3 utilized logistic regression to construct a single linear decision boundary for classification tasks. A perceptron represents this same structural unit from a connectionist perspective: an artificial neuron that aggregates inputs via weights and a bias before applying an activation function. While a single perceptron can emulate fundamental logic gates, the exclusive-OR (XOR) operation reveals the geometric constraints of single-layer systems.

1. Anatomy of a perceptron

A perceptron serves as the baseline computational node in neural architectures. It accepts an input vector, computes its dot product with a weight vector, adds a scalar bias, and passes the aggregate score through an activation function:

\[ z = w^T x + b \] \[ a = \sigma(z) \]
  • \(x_j\) — The input feature components (represented as binary values 0 or 1 within logical operators).
  • \(w_j\) — The scaling weights; a positive value increases the pre-activation score when the corresponding feature \(x_j\) is active.
  • b — The bias term, which shifts the activation threshold along the affine axis independent of feature values.
  • \(\sigma\) — The activation function (see below).

Source: GeeksForGeeks: What is Perceptron?

Activation Functions

An activation function transforms a neuron’s raw output:

\[ z = w^T x + b,\quad a = \sigma(z) \]

It introduces non-linearity, which is necessary for neural networks to learn non-linear patterns.

Activation Formula Key Ideas
Sigmoid \[ \sigma(z) = \frac{1}{1 + e^{-z}} \]
  • Outputs between 0 and 1
  • Used for probabilities
ReLU \[ \text{ReLU}(z) = \max(0, z) \]
  • Zero for negative values
  • Linear for positive values
Tanh \[ \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \]
  • Outputs between −1 and 1
  • Zero-centered (better than sigmoid in some cases)
  • Smoother transitions around 0

Without activation functions, stacking layers would still behave like a single linear model. Activations allow neural networks to learn non-linear decision boundaries.

Source: ResearchGate

2. Linear separation of AND and OR gates

Boolean logic operations function as classification tasks over a binary coordinate space. A single perceptron maps a linear decision boundary through the unit square \([0,1] \times [0,1]\) to separate the truth table coordinates.

AND and OR gates

The AND operator evaluates to 1 exclusively when both inputs are active. The truth table values are: (0,0)\(\rightarrow\)0, (1,0)\(\rightarrow\)0, (0,1)\(\rightarrow\)0, (1,1)\(\rightarrow\)1. Geometric separation requires isolating the upper-right vertex from the remaining three coordinates. Setting parameters to \(w_1 = 1\), \(w_2 = 1\), and \(b = -1.5\) achieves this separation: at coordinate (1,1), the pre-activation is \(z = 1 + 1 - 1.5 = 0.5 > 0\), while at coordinate (1,0), it drops to \(z = 1 - 1.5 = -0.5 < 0\).

The OR operator evaluates to 1 if at least one input is active: (0,0)\(\rightarrow\)0, and all other coordinates map to 1. Initializing parameter weights to \(w_1 = 1\), \(w_2 = 1\), and \(b = -0.5\) balances this condition: coordinate (0,0) yields \(z = -0.5\), whereas coordinate (1,0) yields \(z = 0.5\). While the separating hyperplane shifts position relative to the AND gate configuration, it remains a single linear division.

Both AND and OR distributions are classified as linearly separable. A single linear equation \(w_1x_1 + w_2x_2 + b = 0\) can completely segregate the target classes into opposing half-spaces.

3. The linear non-separability of XOR

The XOR (exclusive-OR) operator evaluates to 1 only when its binary inputs are non-identical: (0,0)\(\rightarrow\)0, (1,0)\(\rightarrow\)1, (0,1)\(\rightarrow\)1, (1,1)\(\rightarrow\)0. The positive class targets sit at vertices (1,0) and (0,1), forming a diagonal distribution across the feature space. No single linear hyperplane can isolate the positive vertices from the negative vertices at (0,0) and (1,1).

Source: Linear Separability of Boolean Functions

4. Hidden layers and feature space transformation

Introducing a hidden layer between the input features and the output layer resolves non-linear distributions. Each independent hidden unit projects its own linear hyperplane, and subsequent layers aggregate these intermediate activations:

\[ h = \sigma(W_1 x + b_1) \] \[ \hat{y} = \sigma(W_2 h + b_2) \]

Here, \(h\) represents the hidden-layer activations, while \(\hat{y}\) represents the network's final prediction.

To decode the XOR problem using a two-unit hidden layer, hidden unit A can be parametrized to evaluate a combined threshold for the input components, while hidden unit B isolates cross-axis variances. The final output node evaluates the intermediate activation vector \(h\), utilizing the hidden layer as an altered coordinate space where the original non-linear vertices become linearly separable.

By expanding hidden layer dimensions, multi-layer networks can approximate complex, high-dimensional decision boundaries in the primary input plane. This capacity for universal function approximation forms the foundational basis for deep network architectures, though it increases empirical variance and risk of overfitting on small datasets.
