Partial Derivatives and the Gradient

Until now, we have studied functions of a single variable, such as \(f(x)\). In many real-world problems, however, functions depend on more than one variable.

For example, a surface might depend on two inputs:

\[ f(x,y) \]

This could represent elevation on a landscape or temperature over a region.

1. What Is a Partial Derivative?

A partial derivative measures how a function changes when we change only one variable at a time, while keeping the other fixed.

\[ \frac{\partial f}{\partial x}, \quad \frac{\partial f}{\partial y} \]

As functions of 2 variables will require 3 dimensions to graph, we can think of it as slicing the surface:

  • \(\frac{\partial f}{\partial x}\): slope when moving in the x-direction
  • \(\frac{\partial f}{\partial y}\): slope when moving in the y-direction

Example: Partial Derivatives of a Simple Surface

Let’s compute the partial derivatives of the function:

\[ f(x,y)=x^2+y^2 \]

This function represents a smooth “bowl-shaped” surface. Every point on the surface has a slope in both the x-direction and y-direction.

To compute \(\frac{\partial f}{\partial x}\), we treat \(y\) as a constant:

\[ \frac{\partial}{\partial x}(x^2+y^2)=2x \]

Now, to compute \(\frac{\partial f}{\partial y}\), treat \(x\) as constant:

\[ \frac{\partial}{\partial y}(x^2+y^2)=2y \]

2. The Gradient

The gradient combines all partial derivatives into a vector:

\[ \nabla f(x,y)=\left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}\right) \]

The gradient points in the direction of the steepest increase of the function.

More generally, for a function of \(n\) variables \(f(x_1,x_2,\ldots,x_n)\),

\[ \nabla f(x_1,x_2,...,x_n)=\left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2},\ldots, \frac{\partial f}{\partial x_n}\right) \]

3. The Multivariable Chain Rule

So far, we have assumed that the variables \(x\) and \(y\) change independently. However, in many applications they both depend on another variable, such as time.

Suppose we have a function

\[ f(x,y) \]

where

\[ x=x(t), \qquad y=y(t) \]

As \(t\) changes, both \(x\) and \(y\) change simultaneously. To determine how quickly the function itself changes, we use the multivariable chain rule:

\[ \frac{df}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} \]

Each partial derivative measures how sensitive the function is to one variable, while the derivatives \(\frac{dx}{dt}\) and \(\frac{dy}{dt}\) describe how quickly those variables are changing.

Let's take a look at an example:

\[ f(x,y)=x^2+y^2 \]

where

\[ x=t, \qquad y=t^2 \]

Now, what is \(\frac{df}{dt}\)? From our earlier work, the gradient is

\[ \nabla f=(2x,2y). \]

Since

\[ \frac{dx}{dt}=1, \qquad \frac{dy}{dt}=2t, \]

the chain rule gives

\[ \frac{df}{dt} = 2x(1) + 2y(2t). \]

Substituting \(x=t\) and \(y=t^2\),

\[ \frac{df}{dt} = 2t+4t^3. \]

Example: An Asymmetric Surface

The previous example was very symmetric because the \(x\) and \(y\) terms were simply added together. Now consider a function where the variables interact:

\[ f(x,y)=x^2y \]

Unlike the previous example, the slope in one direction now depends on the value of the other variable. This means the behavior of the surface changes depending on where you are. Let's calculate the partial derivatives with respect to \(x\) and \(y\):

Treat \(y\) as a constant and differentiate only with respect to \(x\):

\[ \frac{\partial}{\partial x}(x^2y) = 2xy \]

Notice that the result still contains \(y\). This means the slope in the \(x\)-direction changes depending on which horizontal slice (\(y\)-value) we are examining.

Now treat \(x\) as constant:

\[ \frac{\partial}{\partial y}(x^2y) = x^2 \]

Here the slope in the \(y\)-direction depends only on \(x\). For example, when \(x=0\), moving in the \(y\)-direction does not change the function at all. Therefore,

\[ \nabla f(x,y) = \left(2xy,\;x^2\right) \]

Unlike the bowl-shaped surface \(x^2+y^2\), the gradient here is no longer radially symmetric. Its direction and magnitude vary in more interesting ways because each component depends on the location in the plane.

Compare the two examples:
  • \(f(x,y)=x^2+y^2\) gives \(\nabla f=(2x,2y)\), where each partial depends only on its own variable.
  • \(f(x,y)=x^2y\) gives \(\nabla f=(2xy,x^2)\), where the \(x\)-partial depends on both variables.
