What is ML?

Most software operates on explicit rules written by a programmer. Machine learning is the alternative you turn to when those rules become too complex, brittle, or impossible to write manually. This lesson breaks down that core problem and introduces the fundamental components of any machine learning system: data, a model, a loss function, and an optimization loop.

1. Traditional programming

In standard software engineering, you hardcode the decision logic yourself. For example, a bank might evaluate a loan application using standard conditional logic:

IF age >= 18 AND income >= 50000 AND credit_score >= 650 THEN
    approve_loan()
ELSE
    deny_loan()

The inputs are explicit variables from a form, and the output is a binary approval or denial. Given the exact same inputs, the output will never change. This predictability is ideal when business rules are clear and static.

2. Where rules stop working

Spam detection

If you try to write manual rules for a spam filter, you might start with a baseline like "if the subject contains 'FREE', flag as spam." This quickly catches some junk, but it also flags legitimate emails. To fix this, you add rules for links, capitalization, sender reputation, and image structures. However, spammers continuously adapt, requiring endless new branches. The code quickly becomes unmaintainable.

House prices

Square footage is a strong indicator of real estate value, but it isn't a perfect 1:1 relationship. A 1,200 sq ft downtown condo often costs more than a 2,000 sq ft house in a remote suburb. If you try to manually write code account for location, school districts, renovation age, and lot size, the conditional combinations grow exponentially. Instead of an endless list of special cases, you need a mathematical line or curve that best fits historical sales trends.

Image classification

Writing standard code to identify a dog from raw pixels requires translating visual concepts like "ears," "snouts," or "fur" into pixel values. This approach breaks down immediately if the dog is lying on its side, partially hidden in shadow, or captured from a distance. Rather than spelling out manual rules, a system trained on thousands of labeled photos can identify patterns across raw pixel arrays automatically.

3. The machine learning approach

Instead of manually hardcoding every logical branch, you provide the system with examples consisting of inputs paired with the correct outputs. The model functions as a mathematical equation with adjustable variables, known as weights and biases. The training process systematically tweaks these variables until the model's predictions align with your examples.

A recommendation engine does not rely on hardcoded logic like "user 16 always receives basketball content." Instead, it logs user interactions—watches, skips, and rewatches—and calculates preferences across millions of historical data points. The underlying pattern resides in the data, and the model learns the weights automatically.

4. House size and price

This scatter plot demonstrates the core concept. Each point represents an individual house, with size plotted on the horizontal axis and sale price on the vertical axis. Real-world factors like neighborhood, house condition, and garage space mean the points do not line up perfectly, but the upward trend is clear.

Finding the line of best fit manually would mean guessing random slope and intercept numbers. Machine learning automates this process: the algorithm tests parameters, measures the total error, adjusts the numbers, and repeats. This specific loop is known as linear regression.

5. The training loop

Supervised machine learning models rely on a consistent four-step execution cycle:

  1. Data — Labeled historical examples (x, y).
  2. Model — A mathematical function with parameters θ that calculates a prediction ŷ.
  3. Loss — A single quantitative metric indicating prediction error.
  4. Update — Adjusting parameters θ to minimize the loss, then starting the next iteration.

Written compactly:

Data → Model → Loss → Update Loop

While the model architecture changes (from simple lines to neural networks), this foundational loop remains identical.
