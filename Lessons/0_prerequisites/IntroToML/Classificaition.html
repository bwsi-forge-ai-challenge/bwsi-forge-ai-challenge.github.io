Classification and Logistic Regression

Lesson 2 implemented a linear optimization framework to predict continuous real values along a trend line. However, many core problems require assigning instances to discrete categories—such as pass versus fail, or species identifiers. Restricting model outputs to valid probability ranges between 0 and 1 requires a non-linear activation function and an alternative objective function.

1. Classification frameworks

Classification algorithms map inputs to discrete, categorical target tokens, distinguishing them from regression algorithms which predict continuous quantitative scales. In binary classification systems, targets are formally represented as \(y \in \{0, 1\}\), where 0 corresponds to the negative class baseline and 1 denotes the positive class.

Evaluating an unconstrained linear score vector \(z = w_0x_0 + w_1x_1 + b\) can yield arbitrary real outputs. Because these unbounded scalars violate probability axioms, a mapping function is required to compress any real number into an open interval between 0 and 1.

Iris flowers

The standard Iris benchmark dataset records sepal lengths and widths across distinct botanical varieties. Isoradial isolation of the versicolor (designated class 0) and virginica (designated class 1) variants reveals clear statistical distributions: versicolor specimens typically display shorter, wider sepals, whereas virginica specimens exhibit elongated, narrower structures. Plotting sepal length against width reveals overlapping coordinate clusters that, while not linearly separable, can be effectively bisected by an optimized decision boundary.

Pass or fail

Consider a trial tracking preparation time and sleep duration for 30 students. Empirical patterns demonstrate that individuals passing the assessment cluster above 5 study hours and 6 sleep hours, while insufficient study hours coupled with high sleep metrics correlate strongly with failure. A logistic model optimizes weights for both features to output conditional probabilities: \(P(\text{pass}) = \sigma(w_1 \cdot \text{study} + w_2 \cdot \text{sleep} + b)\). Under an optimized weight matrix, a coordinate of 8 study hours and 7 sleep hours evaluates to \(\hat{y} = 0.91\), while a coordinate of 2 and 4 yields \(\hat{y} = 0.12\).

2. The sigmoid activation function

Logistic regression passes unconstrained linear combinations through the sigmoid (or logistic) function:

\(\sigma(z) = \frac{1}{(1 + e^{−z})}\)

As \(z \to \infty\), \(\sigma(z)\) asymptotically approaches 1, and as \(z \to -\infty\), \(\sigma(z)\) approaches 0. At the origin (\(z = 0\)), the function evaluates exactly to \(\sigma(0) = 0.5\). The combined system is parametrized as \(\hat{y} = \sigma(w^T x + b)\), which explicitly estimates the conditional probability \(P(y = 1 \mid x)\).

Evaluating the first derivative—essential for calculating gradient updates during backpropagation—yields:

\[\sigma'(z) = \sigma(z)(1 − \sigma(z))\]

At \(z = 0\), the derivative peaks at \(\sigma'(0) = 0.25\), defining the maximum velocity of change along the function's curve. As the input diverges from zero, the gradient flattens dramatically (\(\sigma'(z) \to 0\)), a property that induces vanishing gradients when stacking multiple non-linear layers in deep architectures.

3. Cross-entropy loss

Mean Squared Error is mathematically unsuited for probabilistic targets: predicting \(\hat{y} = 0.9\) when the true label \(y = 1\) scales to an error contribution of \((1 - 0.9)^2 = 0.01\), which provides insufficient optimization signals. The binary cross-entropy loss function exponentially penalizes incorrect classifications based on confidence:

\[L = −(1/n) \Sigma_i [ y_i \log(\hat{y}_i) + (1 − y_i) \log(1 − \hat{y}_i) ]\]

When evaluating a true positive label (\(y = 1\)), an underestimation of \(\hat{y} = 0.1\) incurs a loss of \(-\log(0.1) \approx 2.30\). Conversely, an accurate estimation of \(\hat{y} = 0.9\) drops the loss to \(-\log(0.9) \approx 0.11\). This asymmetric logarithmic scaling means a fixed error gap in probability space penalizes the model 20 times more severely when the system outputs a confident, incorrect prediction.

For a true negative target (\(y = 0\)) where the model mistakenly predicts \(\hat{y} = 0.99\), the loss scales to \(-\log(0.01) \approx 4.61\). Under identical conditions, an MSE objective function would yield a benign penalty of \((0 - 0.99)^2 \approx 0.98\), failing to generate the necessary gradient push to correct the confident error.

4. Decision boundaries and thresholds

The decision boundary represents the locus of points where the model evaluates the conditional probability exactly at 50% (\(\hat{y} = 0.5\), or equivalently, \(z = 0\)). In a two-dimensional feature domain with coordinates \(x_0\) and \(x_1\), this boundary describes a straight line for standard logistic models: vectors on one side map to class 1, while coordinates on the inverse side map to class 0.

While the classification threshold defaults to 0.5, this hyperparameter can be shifted depending on objective constraints. Elevating the decision threshold to 0.7 requires greater model confidence to assign the positive label, reducing false-positive rates at the expense of introducing more false negatives. Lowering the threshold to 0.3 produces the inverse trade-off. Adjusting this decision cutoff changes the class assignment rules without modifying the underlying boundary line or parameter weights.

When data clusters overlap significantly within the feature space, complete linear separation becomes impossible. Under these conditions, classification accuracy asymptotes below 100%, indicating that a single linear decision hyperplane has reached its structural limits and requires non-linear mapping transformations or higher-capacity models.
